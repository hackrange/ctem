Daily backups

Daily backups use BACKUP_ENCRYPTION_PASSWORD from the server's .env. Backups you take by hand, safety backups and uploads are never deleted automatically.

Database

Every night at 02:15 UTC CTEM vacuums and analyzes the tables that need it, and on Sundays rebuilds indexes that are measurably bloated, without locking them. Busy tables get autovacuum thresholds sized for them.

A restore replaces everything on this server with the backup: data, users, settings and encryption keys. The agent takes a safety backup first, and the app is offline for a few minutes while it runs. Everyone, you included, may need to sign in again afterward. This server keeps its own docker-compose.override.yml and nginx.conf.
Restores from this page are turned off on this server (MAINTENANCE_UI_RESTORE=false). Run sudo bash install.sh --restore FILE on the server instead.

2. Check it opens

3. Restore

Type RESTORE to confirm.
