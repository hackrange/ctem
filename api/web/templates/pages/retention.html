Data retention

When a host counts as gone and its findings are removed, not kept as history

{% include "partials/admin_tabs.html" %}
Gone hosts

"Seen" is any sign of life: a scan, an EDR check-in, a directory logon, a finding a tool still reports, a cloud inventory row, a probe answer. Nothing is removed on a guess: every unseen host is put on the network probe's list first, and only one the probe tried and that didn't answer (no ping, nothing on the common ports) loses its findings. A host with no internal address can't be checked, so it keeps them. The asset record stays.
